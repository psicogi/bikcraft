#  Bikcraft - Bicicletas Elétricas

O **Bikcraft** é um site institucional e e-commerce fictício desenvolvido para uma marca de bicicletas artesanais.

---

##  Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web moderno:

* **HTML5:** Estrutura semântica focada em SEO e acessibilidade.
* **CSS3:** Layouts complexos utilizando **Grid Layout** e **Flexbox**.
* **JavaScript (ES6+):** Implementação de interatividade dinâmica e manipulação do DOM.
* **UI/UX Design:** Foco na experiência do usuário, tipografia e hierarquia visual.

---

##  Funcionalidades e Diferenciais

* **Layout Responsivo:** Adaptado para dispositivos móveis, tablets e desktops (Mobile First).
* **Interatividade com JS:**
    * Menu hambúrguer dinâmico.
    * Galeria de imagens interativa.
    * Sistema de Perguntas Frequentes (FAQ) com efeito sanfona (Accordion).
    * Validação simples de formulários.
* **Performance:** Imagens otimizadas e código organizado para carregamento rápido.
